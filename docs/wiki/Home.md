# Learn and use VOID

VOID is a statically typed language with native compilation, JIT execution and
managed memory. Start with a small program, then build on it one concept at a time.

```void
func main():
    var names = ["Ada", "Lin"]
    for name in names:
        print("Hello, {name}!")
```

The program prints a greeting for each name. You will learn the loop in
[Language basics](https://github.com/Shmellyorc/Void.Language/wiki/Language-basics) and the list in [Collections](https://github.com/Shmellyorc/Void.Language/wiki/Collections).
To run it now, follow [Installation](https://github.com/Shmellyorc/Void.Language/wiki/Installation) and [Your first program](https://github.com/Shmellyorc/Void.Language/wiki/First-program).

## Current status

VOID is under active development. This Wiki teaches implemented language behavior;
[Status and further reading](https://github.com/Shmellyorc/Void.Language/wiki/Resources-and-status) separates current capabilities,
planned work and platform limits. The [language specification](https://github.com/Shmellyorc/Void.Language/blob/main/docs/LANGUAGE_BIBLE.md)
is the precise contract; this Wiki supplies explanations and examples.
