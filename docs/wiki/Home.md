# Learn and use VOID

_Draft for Boss approval; repository documentation is canonical._

Start with [Installation](Installation.md), then [Your first program](First-program.md).
VOID is a statically typed language with native compilation, JIT execution and
managed memory. It is under active development; feature guides describe the
implemented subset while the Language Bible also contains future design.

| I want to… | Guide |
| --- | --- |
| Install the compiler and language server | [Installation](Installation.md) |
| Print a message and build my first application | [First program](First-program.md) |
| Read and write ordinary code | [Language basics](Language-basics.md), [Types](Types.md), [Functions](Functions.md) |
| Store and share data | [Collections](Collections.md), [Managed memory](Managed-memory.md) |
| Understand suspension and concurrency limits | [Async](Async.md) |
| Create an executable or object | [Native compilation](Native-compilation.md) |
| Find an option or explain an exit code | [CLI commands](CLI-commands.md) |
| Connect an editor or diagnose setup | [Editor setup](Editor-setup.md), [Troubleshooting](Troubleshooting.md) |

The [repository documentation index](https://github.com/Shmellyorc/Void.Language/blob/main/docs/README.md)
is canonical. This Wiki is a task guide, not a second language specification.
The official website is [voidlang.com](https://voidlang.com).
