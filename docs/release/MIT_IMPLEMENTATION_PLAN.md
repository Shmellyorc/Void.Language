A location under `src/` is not proof that all of its content is original, and a location under `third_party/` does not erase ownership of identifiable VOID changes.

`src/runtime/console_terminfo.inc` also dynamically opens host libtinfo/ncurses on Linux and libncurses on macOS. Record this optional external facility in the dependency index; do not copy its libraries or terminal database. Its absence from ELF NEEDED is not proof of no runtime dependency. The audit's absolute SDK paths/RUNPATH portability limitation remains separate; this plan adds no relocation repair.

**Generated native executables:** `build_executable` in `src/native_build.cpp` emits a program object, invokes external Clang as the C++ driver, passes the Runtime and fixture archives, then the HTTP archives/shared-library flags from the native manifest. The linker selects relevant archive members; exact retained third-party code depends on the program/link. Ryu/date/time-zone data can enter through Runtime objects; Linux IDN libraries remain shared dependencies, while Windows/macOS use the recorded platform alternatives. Object-only output is an intermediate requiring a later link, not a complete dependency-cleared application.

The proposed original Runtime/stdlib MIT grant permits covered reuse with MIT notices. It does not put the user's whole program under MIT, grant third-party rights, or establish that every generated executable contains the entire HTTP closure. Provide a downstream attribution guide/index for the **actual** linked code and any libraries copied alongside it. Preserve applicable permissive notices, PSL source information, GNU source/replacement requirements and platform runtime conditions. Do not add automatic notice injection or change executable publication in this task.
