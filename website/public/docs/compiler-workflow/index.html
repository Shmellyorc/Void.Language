Running and building applications

These commands are for developers who already have a compatible VOID development build.

Choose the entry point

Run voidc run main.void for a synchronous application. A zero-argument main can return a process status. Executable top-level statements can also form an application. File-level globals initialize before the selected entry runs.

Try the numeric adapter

The small program on this page uses entry(i32) -> i32. voidc run cartons.void 8 prints its returned integer. An application returning status 2 does not print the number 2.

Build and check

Use voidc check . for diagnostics, voidc build . -o app to link an executable, or voidc emit main.void -o main.o for an object. The LLVM/Clang/LLD 23.1.4 toolchain shares lowering between JIT and native output. Keep the compiler’s matching Runtime and link manifest together.
