Connect objects through ordered notifications.

Complete program for the synchronous entry adapter. The result below is the returned integer.

Declare a reading notification

The sensor owns a measured event carrying one integer. Its publish method is allowed to emit that event; subscribers do not acquire emission authority.

Subscribe a display method

source.measured += screen.show connects the display. The sensor publishes two successive readings. The display first stores the input, then replaces it with the next reading; input 5 leaves screen.reading at 6.

Know when delivery completes

Delivery is synchronous and ordered, so both updates finish before the return. Strong subscriptions keep their receivers alive. Multiple handlers run in subscription order; -= removes the latest matching subscription. Events do not implicitly create async tasks.
