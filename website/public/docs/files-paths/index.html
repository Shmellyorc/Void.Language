LEARN VOID

Files and host paths

Extract a filename and handle a filesystem operation through its result.

Separate the filename

This example asks for the filename in a relative path. It needs no existing file. The name “map.txt” has seven scalars. A failed path operation returns an error, handled here by returning zero.

Open a file deliberately

use io provides io.open(path, io.open_mode.read). Match the result before using the file. read_bytes allows short reads. read_exact asks for an exact byte count.

Finish using the handle

Use close() when the outcome matters, or scoped with for deterministic cleanup. Do not rely on garbage collection to close files. Inspect the returned I/O error for operation, path and partial progress. Host path syntax and separators depend on platform.

Read a fixed-size field

Set VOID_GUIDE_FILE to a three-byte file. Asking for two bytes returns two. Asking for four returns the example’s failure value, −1. The with scope releases the handle on both paths.
