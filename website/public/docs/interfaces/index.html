Interfaces

Describe behavior without tying a function to one struct.

State the required methods

An interface lists the method signatures a value must provide. VOID checks conformance structurally: an implementation supplies compatible methods rather than an implements declaration.

Use a view of the same object

The actor composes a motion value. A movable interface view calls move, and a readonly readable view can call the non-mutating read method. Both views observe the actor’s updated position.

Keep authority visible

A const interface view preserves readonly restrictions. With input 5, moving by 4 gives position 9, and the program returns the two reads added together: 18. Interfaces do not remove visibility or receiver-effect checks.
