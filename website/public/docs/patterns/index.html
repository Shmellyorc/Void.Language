Enums & pattern matching

Match the shape of an outcome and name what you need.

Give variants their own payload

An enum declares named alternatives such as empty, numbers and object. Each alternative can carry its own typed payload. Only the active variant’s payload is used.

Capture explicitly

var introduces a pattern capture. The is expression checks a pattern, and match selects a branch. Patterns compose, so Ok(payload.numbers(var values)) can inspect a successful result and its enum payload together.

Preserve the data model

Capturing a fixed-array payload copies its value storage. Changing the independent copy does not change the array inside the enum held in the list. Input 5 returns the number payload plus the list count: 8. Incomplete matches can warn; an unmatched match expression raises a runtime failure.
