Platform information and directories

Find the host platform or ask for the right application directory.

Inspect the host

os.platform() returns a platform name and os.architecture() identifies the architecture. The example checks whether a name was returned so its numeric result stays portable.

Choose a directory by purpose

Use os.config_dir(app_id) for settings, data_dir for durable data and cache_dir for disposable files. Match their results. A returned path does not create a directory or grant permission to write it.

Locate bundled resources

Use os.resource_dir() for packaged resources instead of assuming the working directory is beside the executable. Environment queries and home or temporary directory lookup can fail. Keep host-specific paths out of portable configuration.
