Modules & imports

Organize a program into small source files.

Complete program for the synchronous entry adapter. The result below is the returned integer.

Keep the module paths together

Download the entry file and supporting sources below. Save them with the displayed filenames, including the nested details/rates.void path. The entry file’s parent establishes the virtual project root.

main.void
pricing.void
delivery.void
details/rates.void

Use qualified and direct names

The absolute project-root import is aliased as pricing, so its function is called as pricing.subtotal. The relative delivery import exposes its unambiguous name directly. Five items at four plus delivery of three return 23.

Read paths in project context

A leading slash refers to the virtual project root, not the operating-system root. A quoted path, with or without ./, resolves from the importing file. Exact-case .void filenames and forward slashes are required. Parent paths remain bounded by the project root; a package manager is not supplied.

Follow paths from the importing file

use "details/rates.void" as rates inside pricing resolves from that file’s directory, just like ./details/rates.void. Keep the directory when downloading this supporting module.

Unquoted use io/files as files illustrates nested standard-source spelling. It resolves io/files.void under the compiler’s selected standard-source root. An absolute VOID_STDLIB_ROOT override can select that root; otherwise the compiler’s configured source root is used. This is syntax only: no shipped io/files module or filesystem API is promised. Standard sources cannot import quoted project files. Importing a native provider never grants host trust.

Find the project entry deliberately

With a compatible local compiler, voidc run . --app discovers main.void. Directory-based check and emit use the same discovery. From an active file, discovery looks for the nearest exact main.void through parent directories up to the workspace boundary. Without an active file, only the workspace root is checked; there is no recursive search. An explicitly selected entry wins, source errors never trigger a fallback, and the selected entry remains fixed during a session until deliberately changed or restarted.

The complete source above uses the legacy entry(i32) adapter: run it with a numeric input, not --app. See application entry for a main-based program. These workflows describe implemented compiler behavior, not a public download or installation command.
