Structs & memory

Choose value copies or shared objects for your data.

Complete program for the synchronous entry adapter. The result below is the returned integer.

Copy a value independently

The first program copies a position value, then moves only the copy by three. Input 5 leaves original.x at 5 while moved.x becomes 8. Returning the original makes the independence visible.

Share a managed object

The second program uses an ordinary managed struct. Both basket names refer to one object. Adding three items through shared_basket is visible through basket, so input 5 returns 8.

Separate memory from resources

The tracing garbage collector reclaims unreachable managed objects without manual frees. A value struct containing managed references still shares the referenced objects when copied. Readonly views preserve their access restrictions. External-resource release is separate from garbage collection; use deterministic cleanup for scoped ownership.
