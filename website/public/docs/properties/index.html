Compute area from current fields

A rectangle stores width and height; its area getter computes their product. There is no cached area field to update when dimensions change.

Read after a change

The garden begins with width four and height three. Extending the width by input 5 gives width nine; garden.area then reads 27. With no extension, the area is 12.

Keep access intentional

The property has no setter, so callers cannot assign to garden.area. A setter can be defined when assignment has a clear meaning. Getters cannot mutate their receiver; fallible operations use explicit methods.
