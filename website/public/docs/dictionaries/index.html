Dictionaries

Associate keys and values while preserving insertion order.

Use a typed mapping

A dictionary literal associates keys with values. Repeating a key in this example replaces its value without moving its original insertion position. Adding a new key appends a new entry.

Work with membership and order

contains checks for a key, remove reports whether it removed one, and clear empties the dictionary. Iteration uses for item, key in stats; reverse visits the current insertion order backwards.

Share the mapping intentionally

alias and stats refer to the same dictionary. Updating a value through one view is visible through the other. The example saves input 5 plus a count of 3 before clearing the dictionary, then returns 8. Do not assume proposed get or pop APIs exist.
