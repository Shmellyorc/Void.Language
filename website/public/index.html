THE ROAD AHEAD

Built with intention.
Growing with evidence.

VOID is growing toward a clear goal: a language that feels approachable, compiles to native code and gives your ideas room to grow.

Implemented foundation

Language & native execution

The current foundation includes static types, managed and value structs, collections, generics, results and native LLVM compilation.

In development

Developer tooling

Work on language-server capabilities and editor integration aims to make code easier to explore, understand and change.

Future direction

A broader ecosystem

Package management, general native-library loading and automatic hot-reload watching remain future work. No release date is promised.
